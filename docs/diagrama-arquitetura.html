3 · Sequência — Fluxo Completo de uma OS (Happy Path)

sequenceDiagram actor C as Cliente participant MONO as Monolito participant OS as OS Service participant MQ as RabbitMQ participant BILL as Billing Service participant MP as Mercado Pago participant EXEC as Execution Service C->>MONO: POST /os (clienteId, veiculoId) MONO->>MONO: Salva OS local (RECEBIDA) MONO->>OS: POST /ordens (clienteId, veiculoId) OS->>OS: Persiste OS — PostgreSQL (RECEBIDA) OS->>OS: Salva histórico — MongoDB OS->>MQ: Publica os.criada MQ->>BILL: os.criada BILL->>BILL: Gera orçamento BILL->>MQ: Publica orcamento.gerado MQ->>OS: orcamento.gerado OS->>OS: Status → AGUARDANDO_APROVACAO OS->>OS: Salva histórico — MongoDB MONO->>OS: PATCH /ordens/{id}/status (AGUARDANDO_APROVACAO) C->>MONO: GET /os/{id}/aprovar (link do e-mail) MONO->>MONO: Aprova orçamento, baixa estoque MONO->>OS: PATCH /ordens/{id}/status (APROVADA) BILL->>MQ: Publica orcamento.aprovado MQ->>OS: orcamento.aprovado → APROVADA BILL->>MP: Processa pagamento MP-->>BILL: Pagamento confirmado BILL->>MQ: Publica pagamento.confirmado MQ->>OS: pagamento.confirmado → APROVADA MQ->>EXEC: pagamento.confirmado EXEC->>EXEC: Agenda execução EXEC->>MQ: Publica execucao.iniciada MQ->>OS: execucao.iniciada → EM_EXECUCAO EXEC->>EXEC: Realiza diagnóstico e reparo EXEC->>MQ: Publica execucao.finalizada MQ->>OS: execucao.finalizada → FINALIZADA C->>OS: GET /ordens/{id} OS-->>C: OS FINALIZADA + histórico completo

4 · Sequência — Rollback da Saga (Orçamento Rejeitado)

sequenceDiagram actor C as Cliente participant OS as OS Service participant MQ as RabbitMQ participant BILL as Billing Service Note over OS,BILL: OS está em AGUARDANDO_APROVACAO C->>OS: DELETE /ordens/{id}?motivo=Preço alto OS->>OS: Status → CANCELADA OS->>OS: Salva histórico compensação — MongoDB OS->>MQ: Publica os.cancelada MQ->>BILL: os.cancelada BILL->>BILL: Cancela orçamento pendente Note over BILL: Transação compensatória concluída alt Billing já iniciou pagamento BILL->>BILL: Estorna pagamento no Mercado Pago BILL->>MQ: Publica pagamento.falhou MQ->>OS: pagamento.falhou → CANCELADA (idempotente) end
